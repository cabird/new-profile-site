Christian Bird, Ph.D.

Senior Principal Researcher, Microsoft Research

ACM Distinguished Scientist 8 papers honored 10+ years later 8 Distinguished & Best Paper awards 120+ publications

For twenty years I have studied how software is actually built. My work centers on the empirical analysis of source code, version control history, and engineering practice at scale — mining repositories, reviews, builds, and telemetry; surveying and interviewing the engineers who produce them; and building tools that product teams genuinely adopt. I've worked on code review, branching and release strategy, build systems, developer productivity, and most recently AI-assisted software engineering.

Areas of Expertise full descriptions →

  • Source code analysis; detection and characterization of code clones and reused code
  • Software authorship, ownership, and contribution attribution from version control history
  • Version control forensics — Git, Subversion, CVS, Team Foundation Server
  • Reconstruction of development timelines from commit, build, and review records
  • Integrity, completeness, and bias of software engineering records
  • Code review practice and industrial software quality assurance
  • Defect prediction, reliability measurement, and quality metrics at commercial scale
  • AI-assisted code generation, including GitHub Copilot and LLM coding tools
