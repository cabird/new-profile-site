About the talk

Across more than 500,000 developers, coding activity with autonomous agents rose by up to 240 percent. Software releases rose 30 percent. This talk is about where the rest went. It draws on interviews with 30 engineers, managers and product managers working on long-lived products, a survey of 448 developers about how much control they would hand to an AI, a benchmark of AI code reviewers built from real bugs in real pull requests, and 27 matched pairs of developers on the same teams who used the same tools very differently.

The short version: AI made it cheap to start work, so more work started, by more people. Review, testing, integration and deployment got no faster, and the people who do that work did not multiply. Expectations treated generating code and shipping it as the same thing, and that is where work got dropped. Better models help with part of it. The rest is how we measure, staff and protect the work after the diff.
